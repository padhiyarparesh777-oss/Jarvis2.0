# JARVIS 2.0

Your Personal AI Phone Manager & Creator.

## Project identity
- **App name:** JARVIS 2.0
- **Application ID:** `com.jarvis.pakage`
- **Platform:** Android
- **Language:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Theme:** Adaptive light / dark

## Phase 1 — UI Foundation
This initial scaffold contains:
- Android Gradle project configuration
- Jetpack Compose Material 3
- Adaptive system light/dark theme
- Home dashboard with quick-action cards
- Chat input shell and bottom navigation

## Build
Open the project in Android Studio, or build with a compatible local Gradle installation:

```bash
gradle :app:assembleDebug
```

The project uses Android Gradle Plugin 8.13.2, Kotlin 2.2.21, compile SDK 36 and minimum SDK 24.
